# BPH Universal Network Discovery: installers

This repository holds only the released installers of BPH Universal Network Discovery, a Windows tool for BPH installers that finds the devices on a site network. The source code is not here.

## Install
Download the newest `BPH-Network-Discovery-<version>-x64.msi` from [Releases](https://github.com/imanmos/bph-network-discovery-releases/releases/latest) and run it (administrator rights needed). Everything is installed by it; for full discovery also install the free [Npcap](https://npcap.com/#download).

## Updates
The installed program looks here for a new version and updates itself when you click **Update now** in its window. It installs only an installer that carries a valid BPH signature (`.bphsig` next to each installer).
